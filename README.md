
# Rutina de Gimnasio - Grappling & Columna Sana

## Instrucciones para publicar en GitHub Pages
1. Crea un nuevo repositorio en GitHub (ej. `rutina-lucha`).
2. Sube todos los archivos de esta carpeta (`index.html`, `css/`, `js/`, etc.) a la rama `main` de tu repositorio.
3. En tu repositorio en GitHub, ve a **Settings** (Configuración).
4. En el menú lateral izquierdo, haz clic en **Pages**.
5. Bajo **Build and deployment**, en la sección **Source**, selecciona `Deploy from a branch`.
6. Bajo **Branch**, selecciona `main` y la carpeta `/ (root)`, luego haz clic en **Save**.
7. Espera unos minutos y GitHub te dará la URL de tu página web en vivo.
